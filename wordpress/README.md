# Brobobber на WordPress

Тема и плагин для WordPress 7.1.5 (PHP 7.4 и новее). Конфигуратор V-Rod в эту версию не входит.

| Файл | Что это |
| --- | --- |
| `dist/brobobber-theme.zip` | Тема: дизайн, страницы, анимации |
| `dist/brobobber-core.zip` | Плагин: проекты, услуги, стили, контакты, тексты, заявки, импорт |
| `dist/brobobber-media.zip` | Фото и видео сайта (93 МБ), нужен, только если хостинг не скачает их сам |

## Установка

1. **Внешний вид → Темы → Добавить → Загрузить тему:** `brobobber-theme.zip`, затем «Активировать».
2. **Плагины → Добавить → Загрузить плагин:** `brobobber-core.zip`, затем «Активировать». Откроется экран импорта.
3. Нажмите **«Импортировать»** и не закрывайте вкладку до надписи «Готово». Файлы скачиваются с `slavadobro.github.io`, поэтому не удаляйте тот сайт до конца импорта.
4. Откройте **Brobobber → Контакты**, впишите настоящее время работы и почту для заявок.

Если хостинг не может скачать файлы с GitHub, распакуйте `brobobber-media.zip` в `wp-content/uploads/` по FTP (появится папка `brobobber-import`) и снова нажмите «Импортировать». После импорта эту папку можно удалить.

Импорт можно запускать повторно: он докачает недостающее и не перезапишет то, что уже отредактировано.

## Что и где редактировать

- **Проекты, Услуги, Стили мотоциклов:** отдельные разделы в меню админки. Порядок задаётся полем «Порядок».
- **Заявки:** все заявки с сайта. Копия приходит на почту из настроек.
- **Brobobber:** контакты, тексты страниц, этапы, FAQ, отзывы, фото страниц, ролики.
- **Внешний вид → Меню:** главное меню.

## Перед запуском

- Настройте отправку почты через SMTP (например, плагином WP Mail SMTP): на многих хостингах письма без этого не доходят. Заявка в любом случае сохраняется в разделе «Заявки».
- На Nginx нужны правила для ЧПУ-ссылок: `try_files $uri $uri/ /index.php?$args;`.

## Для разработчика

```bash
node wordpress/build.mjs
python wordpress/package.py
docker compose -f wordpress/docker-compose.yml up -d
```

`build.mjs` заново генерирует CSS, иконки, шрифты, контент и медиапакет из исходников сайта на Svelte, `package.py` собирает ZIP. Тестовый стенд открывается на `http://localhost:8088`.
