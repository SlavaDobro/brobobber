Посетитель ещё ничего о нас не знает. У него открыта вкладка, есть несколько вопросов и немного времени.

Будущий сайт должен помочь ему разобраться, чем занимается компания, увидеть её подход к работе и найти удобный способ связаться. Brobobber — проект, в котором этот первый разговор обретёт форму.

### Что задумано

| Что важно посетителю | Что предстоит сделать |
| --- | --- |
| Понять, куда он попал | Первый экран с ясным рассказом о компании |
| Узнать подробности | Структуру страниц и содержание по брифу |
| Почувствовать характер бренда | Типографику, цвета и композицию под компанию |
| Комфортно смотреть с телефона | Адаптивные страницы и удобную навигацию |
| Сделать следующий шаг | Заметные контакты и понятные действия |

Анимации планируется использовать для переходов, отклика элементов и акцентов на содержании.

### Где мы сейчас

Техническая основа подготовлена. Установлены Svelte 5, Vite и Tailwind CSS 4, настроены проверка компонентов и сборка. Пока в проекте находится стартовая демостраница.

Следующий этап — бриф компании. После него появятся структура, тексты, визуальная концепция и первые экраны. Разделы и функции в таблице выше описывают направление работы и будут уточняться по брифу.

<details>
<summary><strong>Открыть мастерскую — запуск и проверка проекта</strong></summary>

Для работы нужны Node.js и npm. Проект проверен на Node.js 26.13.0 и npm 12.2.1.

Выполняй команды в папке проекта, где лежит package.json.

Установить зависимости и запустить сайт локально

```powershell
npm.cmd ci
npm.cmd run dev
```

Адрес для браузера появится в терминале.

| Файл | За что отвечает |
| --- | --- |
| `src/App.svelte` | Главный компонент страницы |
| `src/app.css` | Общие стили и подключение Tailwind |
| `src/lib/` | Компоненты для повторного использования |

Проверить компоненты и собрать сайт

```powershell
npm.cmd run check
npm.cmd run build
```

Готовая сборка появится в папке `dist`. Посмотреть её локально можно командой

```powershell
npm.cmd run preview
```
