Посетитель ещё ничего о нас не знает. У него открыта вкладка, есть несколько вопросов и немного времени.

Будущий сайт должен помочь ему разобраться, чем занимается компания, увидеть её подход к работе и найти удобный способ связаться. Brobobber — проект, в котором этот первый разговор обретёт форму.

### Что задумано

| Что важно посетителю | Что предстоит сделать |
| --- | --- |
| Понять, куда он попал | Первый экран с ясным рассказом о компании |
| Узнать подробности | Структуру страниц и содержание по брифу |
| Почувствовать характер бренда | Типографику, цвета и композицию под компанию |
| Комфортно смотреть с телефона | Адаптивные страницы и удобную навигацию |
| Сделать следующий шаг | Заметные контакты и понятные действия |

Анимации планируется использовать для переходов, отклика элементов и акцентов на содержании.

### Где мы сейчас

Реализован прототип конфигуратора V-Rod на странице `/configurator`. Он также открывается с корневого адреса.

- Шесть ракурсов с сохранением выбранных деталей: два профиля, два вида три четверти, анфас и вид сзади.
- Четыре цвета кузова, два варианта кожи и два варианта выхлопа.
- Демонстрационный расчёт стоимости кастомизации.
- Сохранение настроек в браузере и восстановление сборки по ссылке.
- Скачивание текстовой спецификации. Все действия остаются внутри страницы конфигуратора.
- Адаптивная страница, управление кнопками и свайпами, учёт настройки уменьшения анимации.

Визуализации сгенерированы на основе [проекта V-Rod мастерской](https://brobobber.moscow/v-rod). Это концептуальные изображения с шестью фиксированными ракурсами. Точность геометрии, совместимость деталей и цены нужно согласовать с мастерской перед коммерческим запуском.

Следующий этап — согласование конфигуратора, настоящего каталога деталей и структуры остальных страниц.

<details>
<summary><strong>Открыть мастерскую — запуск и проверка проекта</strong></summary>

Для работы нужны Node.js и npm. Проект проверен на Node.js 26.13.0 и npm 12.2.1.

Выполняй команды в папке проекта, где лежит package.json.

Установить зависимости и запустить сайт локально

```powershell
npm.cmd ci
npm.cmd run dev
```

Адрес для браузера появится в терминале.

| Файл | За что отвечает |
| --- | --- |
| `src/App.svelte` | Главный компонент страницы |
| `src/app.css` | Общие стили и подключение Tailwind |
| `src/lib/` | Компоненты для повторного использования |
| `src/lib/configurator.js` | Каталог вариантов, цены и восстановление настроек |
| `src/lib/BikeViewer.svelte` | Ракурсы, визуализация материалов и анимация |
| `public/images/` | Два основных листа ракурсов и общий лист видов спереди/сзади для обоих выхлопов |

Проверить компоненты и собрать сайт

```powershell
npm.cmd run check
npm.cmd run build
```

Готовая сборка появится в папке `dist`. Посмотреть её локально можно командой

```powershell
npm.cmd run preview
```

Для запуска в Docker

```powershell
docker compose up --build -d
```

Открой [локальный конфигуратор](http://localhost:8080/configurator). Контейнер сам устанавливает зависимости, проверяет компоненты и собирает приложение. Порт доступен только на этом компьютере.

После изменений повтори команду с `--build`. Для остановки выполни `docker compose down`.

</details>
