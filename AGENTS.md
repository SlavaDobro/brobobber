# Работа с проектом

Проект использует Svelte 5, Vite и Tailwind CSS 4.

## Коммиты и отправка на GitHub

Пользователь разрешил коммитить и отправлять завершённые изменения, выполненные агентом в рамках задачи, в репозиторий `origin` (`SlavaDobro/brobobber`). Повторное подтверждение для обычных коммитов и push не требуется, если пользователь не ограничил текущую задачу.

- Перед изменениями проверяй `git status` и текущую ветку. Сохраняй чужие незакоммиченные изменения и включай в коммит только файлы или фрагменты своей задачи.
- Перед коммитом проверяй diff. Для изменений кода или зависимостей выполняй `npm.cmd run check` и `npm.cmd run build`, исправляй найденные ошибки. Для изменений только документации достаточно проверки diff.
- По завершении задачи создай коммит с понятным описанием и выполни обычный push в соответствующую ветку `origin`. Основная ветка проекта — `main`.
- Не отправляй секреты, файлы `.env`, `node_modules` и `dist`.
- Не используй force push и не перезаписывай чужую историю. При отклонённом push сначала получи и изучи удалённые изменения.
- После отправки проверь совпадение локального коммита с удалённой веткой. В ответе сообщи результат и короткий хеш коммита. Если отправка не удалась, явно укажи это.
